# 📊 Pipeline ETL e dashboard de gestão financeira condominial

> Solução de ponta a ponta que automatiza a extração e o tratamento de relatórios contábeis complexos de administradoras.
---
Um pipeline em Python (Google Colab) faz a ingestão e a normalização, carrega os dados no Google Sheets e alimenta um dashboard interativo no Looker Studio.
O foco é auditar o fluxo de caixa, acompanhar séries históricas de créditos e débitos, controlar a inadimplência e apoiar planos de ação para recuperar o caixa ordinário.
Python, Pandas, Google Sheets API, Looker Studio, ETL, Análise estatística

## 🚀 Principais Projetos Exibidos

1. **Finalidade**
   *  Focado em auditoria de fluxo de caixa, controle de inadimplência e apoio a planos de ação gerenciais. Permite observar custos e receitas por centro de custo (contas), lançamentos detalhados por nota fiscal.

2. **Pipeline ETL**
   * Solução de ponta a ponta para automação de extração, tratamento de dados contábeis complexos (via Python / Google Colab) e carga estruturada em Google Sheets.

3. **Dashboad**
   *  Modelagem de visualização interativa no Looker Studio. Focado em auditoria de fluxo de caixa, controle de inadimplência e apoio a planos de ação gerenciais.
